# Building Alp

## Prerequisites

```bash
brew install gnupg           # GPG binary (required at runtime)
brew install pinentry-mac    # GUI passphrase dialog (required at runtime)
brew install --cask tuist    # Xcode project generation
```

You need **Xcode 26** or later and an Apple Developer account (free or paid).

## Configure Signing

Before building, set your Apple Developer Team ID and bundle ID prefix at the top of `Project.swift`:

```swift
let teamID = "YOUR_TEAM_ID"        // e.g. "ABCDE12345"
let bundlePrefix = "com.yourcompany" // e.g. "com.example"
```

All bundle IDs, entitlements, Mach service names, XPC code signing requirements, and the LaunchAgent plist are derived from these two variables automatically. No other files need editing.

## Generate & Build

```bash
# 1. Generate the Xcode project (not committed to git)
tuist generate

# 2. Open in Xcode
open Alp.xcworkspace

# 3. Build & Run the Alp scheme (⌘R)
```

Or build from the command line:

```bash
xcodebuild build \
  -workspace Alp.xcworkspace \
  -scheme Alp \
  -destination 'platform=macOS' \
  -configuration Debug
```

## First Run

1. In the running app, click **"Install Helper"** to register the background agent.
2. Open **Mail → Settings → Extensions** and enable **Alp**.
3. Compose a new message — the Sign/Encrypt toolbar should appear.

## Running Tests

```bash
# Via Xcode
# ⌘U with the Alp scheme selected

# Via command line
xcodebuild test \
  -workspace Alp.xcworkspace \
  -scheme Alp \
  -destination 'platform=macOS'
```

Tests require `gpg` installed and at least one secret key in your keyring. They dynamically discover the first available key — no configuration needed.

## Project Structure

```
Alp/                    Main app — settings UI + helper installer
AlpExtension/           Mail extension — MailKit protocols, compose toolbar
AlpHelper/              XPC helper agent — calls gpg binary (unsandboxed)
Shared/                 Code shared across all targets
Tests/                  Unit tests
Project.swift           Tuist manifest (defines all targets and settings)
```

The `.xcodeproj` and `.xcworkspace` are generated by Tuist and **not committed** to git. Always regenerate after changing `Project.swift`.
